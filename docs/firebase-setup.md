# Firebase preparation
No cloud project, paid resource, account login or credentials have been created. Use your own Firebase Console to create/select a project when authorized. Register the Angular web app and Android com.familyguard.child (debug suffix .debug needs its own registration). Enable an approved Authentication provider; register Android signing fingerprints. Download google-services.json locally, never commit it. Add the Google services Gradle plugin only after the file exists. Firebase Auth/FCM packages are declared; no initialization or token handling is implemented.

Set FIREBASE_PROJECT_ID and GOOGLE_APPLICATION_CREDENTIALS in ignored backend .env with a service account file outside source. Before protected routes, integrate a maintained server verification SDK and validate issuer, audience, signature, expiry and revocation as required. Never use client Firebase configuration as a server credential. Web Firebase public config belongs in environment-specific configuration; private keys never do. FCM contains opaque event IDs; fetch private details through authenticated API. Firebase CLI is project-local; use npx firebase --version, and do not run login/init/deploy without an intentional account workflow. Billing is not enabled.
