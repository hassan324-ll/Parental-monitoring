# FamilyGuard API rules
Follow ../../AGENTS.md. This is a REST API application. Use the project-local .tools/php runtime through scripts/common.ps1 because global Herd PHP lacks PostgreSQL support. Do not add agent tooling or global installers unless needed for the user's task. Keep family authorization in policies, input validation in FormRequests and business operations in services. Only the public health route exists in Phase 1. Run PHP tests on SQLite and a separate PostgreSQL test database. Never run RefreshDatabase against familyguard development data. Format PHP with vendor/bin/pint.
